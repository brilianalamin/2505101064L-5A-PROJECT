Website Informasi Kampus merupakan website sederhana yang menyediakan informasi akademik dan kegiatan mahasiswa.

1. Unduh atau clone repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `uts/index.html`.
4. Jalankan menggunakan ekstensi Live Server.
